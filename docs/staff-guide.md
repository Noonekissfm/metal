# Как менять каталог на сайте met-c.ru

Адрес админки: **https://met-c.ru/pb/_/**
Логин и пароль выдаёт администратор. Меняются данные сразу — сайт обновится
у посетителей в течение 10 минут (или мгновенно, если обновить страницу с Ctrl+F5).

Админка на английском. Ниже — что как называется.

| Кнопка/поле в админке | Что это на самом деле |
|---|---|
| **Collections** (слева) | разделы базы: товары, категории, заказы, настройки |
| **products** | товары |
| **categories** | категории каталога |
| **orders** | заказы с сайта |
| **settings** | общие настройки (скидка) |
| **New record** | добавить запись |
| **Search** | поиск по списку |
| **Save** | сохранить |

## Товар (products)

| Поле | Что писать |
|---|---|
| `key` | адрес товара латиницей, например `krug-40-stal-45`. **Менять нельзя** — сломается ссылка |
| `title` | название, как видит покупатель |
| `category` | категория; начните печатать название, выберите из списка |
| `description` | описание |
| `price` | цена за тонну, **без скидки**. Пусто = берётся цена категории |
| `image` | картинка (jpg/png, до 5 МБ) |
| `image_legacy` | старая картинка из каталога — не трогать |
| `menu_path` | «хлебные крошки» — заполняется автоматически при переносе |
| `sort_order` | порядок в списке: меньше число — выше в списке |
| `active` | галочка снята — товар исчезает с сайта, но ссылка не ломается |

## Цены: главное

Цена ищется так:

1. если у товара заполнено `price` — берётся оно;
2. если пусто — берётся `base_price` его категории;
3. если и там пусто — поднимаемся к категории выше;
4. если нигде нет — на сайте пишется «Уточнить стоимость по телефону».

Из этого следуют два рабочих приёма.

**Поднять цену всей категории.** Откройте `categories`, найдите категорию,
поставьте новое значение в `base_price`, Save. Цена изменится у всех товаров
этой категории и всех вложенных, **у которых `price` пустое**.

**Изменить цену одного товара.** Откройте товар в `products`, впишите `price`,
Save. Этот товар перестаёт слушаться категории.

**Вернуть товар к цене категории.** Очистите `price` у товара, Save.

Цены хранятся **без скидки**. Скидка задаётся один раз в `settings` →
`discount_percent` (сейчас 2) и вычитается на сайте автоматически. Если
написать в `price` 100 000, покупатель увидит 98 000.

При переносе каталога цены, одинаковые для всей категории, были подняты в
`base_price` категории — таких категорий 89. Если в такой категории понадобятся
разные цены, просто впишите нужным товарам своё `price`, остальные останутся
на цене категории.

## Добавить новый товар

1. `products` → **New record**.
2. `key` — латиницей, без пробелов, уникальный (например `list-10-09g2s`).
3. `title`, `category`, `price` (или оставить пустым, чтобы взять цену категории).
4. При желании `image`.
5. `active` — включено.
6. Save.

Товар появится на странице своей категории и его можно будет положить в корзину.

## Убрать товар

Снимите галочку `active` и сохраните. Удалять запись не нужно: тогда старая
ссылка на товар перестанет открываться, а поисковики её ещё помнят.

## Заказы (orders)

Каждый заказ с сайта приходит письмом на `info@met-c.ru` и одновременно
сохраняется в `orders` — на случай, если письмо потеряется. Поля: телефон, имя,
комментарий, список позиций, сумма и `status` (`new` → `called` → `done`
или `cancelled`). Статус можно менять вручную, чтобы не звонить дважды.

## Чего делать не стоит

- менять `key` у существующих товаров и категорий — ломаются ссылки и реклама;
- удалять категории — вместе с ними «повиснут» товары;
- менять структуру полей (**New field**, **Delete field**) — это работа
  разработчика.

Если что-то пошло не так — ночная копия базы делается каждый день, откатить
можно на любой день из последних двух недель.
