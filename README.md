# metal

Сайт компании МЕТ-С — https://met-c.ru. React 18 + CRA 5, TypeScript.

Каталог больше не лежит в репозитории: товары, категории и цены хранятся в
PocketBase, сотрудники правят их сами через админку. Бэкенд (приём заявок и
заказов) — в соседнем репозитории `metal-api`.

## Запуск

Без бэкенда каталог не загрузится, поэтому запускать нужно обе части.

**Терминал 1 — PocketBase и API:**

```sh
cd ../metal-api
./dev.sh --setup     # первый раз: скачает PocketBase, создаст коллекции, перенесёт каталог
./dev.sh             # дальше просто запуск
```

`--setup` берёт каталог из `../metal/src/data/data.json`. Этого файла больше
нет в репозитории, возьмите его из истории:

```sh
git show b815cc9:src/data/data.json > /tmp/data.json
cd ../metal-api && DATA_PATH=/tmp/data.json ./dev.sh --setup
```

Письма локально не отправляются — их текст печатается в консоль (`EMAIL_ENABLED=0`).
Если порт 8090 занят: `PB_PORT=8099 ./dev.sh` и тот же порт в `REACT_APP_PB_URL`.

**Терминал 2 — сайт:**

```sh
npm install
npm start
```

Создайте `.env.local`, чтобы фронтенд смотрел на локальный бэкенд, а не на боевой:

```
REACT_APP_API_URL=http://127.0.0.1:8080
REACT_APP_PB_URL=http://127.0.0.1:8090
```

Сайт — http://localhost:3000, админка каталога — http://127.0.0.1:8090/_/
(логин `admin@met-c.local`, пароль `Test12345678`).

| Переменная | По умолчанию | Что это |
|---|---|---|
| `REACT_APP_API_URL` | `https://met-c.ru` | aiohttp: заявки и заказы |
| `REACT_APP_PB_URL` | `https://met-c.ru/pb` | PocketBase: каталог |

Сборка — `npm run build`, содержимое `build/` выкладывается на сервер.

## Как устроен каталог

- `src/api/catalog.ts` — запросы к PocketBase.
- `src/context/CatalogContext.tsx` — дерево категорий и настройки грузятся
  один раз за сеанс (~20 КБ) и кэшируются в `sessionStorage`; там же считается
  итоговая цена товара.
- `src/Pages/CategoryPage` — по адресу `/catalog/a/b/c` показывает категорию
  или карточку товара; товары запрашиваются только для открытой категории.
- Цена товара: своя, иначе `base_price` ближайшей категории сверху, иначе
  «уточнить по телефону». Скидка (`discount_percent` в настройках) вычитается
  в `src/utils/price.ts` — и в карточке, и в корзине это одна и та же функция.
- Картинки старого каталога лежат в `public/assets/images/cache/catalog/`
  и раздаются статикой; новые загружаются сотрудниками в PocketBase.

**Про `require(\`src/${путь}\`)`:** так подставлять картинки нельзя. Webpack
не знает значение переменной и на всякий случай тащит в сборку **весь `src`** —
из-за этого в бандл попадали и каталог, и тесты (лишние 94 КБ gzip). Картинки,
путь к которым известен только во время работы, кладём в `public/` и
подставляем обычной строкой.

## Корзина

- `src/context/CartContext.tsx` — состояние корзины, переживает перезагрузку
  через `localStorage`. Количество — в тоннах, дробное.
- Строка корзины хранит снимок цены на момент добавления; при открытии
  `/cart` цены сверяются с каталогом, изменения показываются покупателю.
- Заказ уходит на `POST /api/v1/order`, сумма пересчитывается на сервере.
